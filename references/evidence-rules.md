# 证据规则（Evidence Rules）

本文件展开 SKILL.md 第 2 节的证据规则，供所有任务模式使用。核心原则：**来源数不等于可信度；搜索未检出不等于不存在。**

## 1. 声明分类

| 类型 | 定义 | 示例 |
| --- | --- | --- |
| 事实 | 可由权威来源在适用范围内直接支持 | 某公告的生效日期、注册证编号、年报披露收入 |
| 厂商宣称 | 利益相关方单方陈述，未独立验证 | 「领先」「首个」「市占第一」 |
| 分析推断 | 基于事实的推理或测算，含假设 | 由价格带测算回本周期、市场外推 |
| 内部假设 | 用户或团队提出、未经证实的判断 | 「我们估计客户愿付 X 万元」 |
| 待验证事项 | 目前无法判断真伪或适用性 | 「该参数是否适用于新版型号」 |

每个关键声明必须归入其中一类并标注；混合型声明拆开标注。

## 2. 证据登记字段

关键声明关联证据ID，逐项记录：

- **原始出处**（URL + 页码/图表号/段落定位，尽量溯源到原始文件而非转载页）
- **渠道类型**：文献 / 专利 / 官网 / 公众号 / 媒体 / 财报 / 数据库等
- **三个日期**：发布日期、数据时点（数据描述的是什么时候）、访问日期
- **适用范围**：地区、型号/版本、样本、时间窗
- **局限**：单中心、小样本、厂商资助、口径不明等
- **核验状态、证据质量、研究成熟度**：三者分别记录（见第 3 节）

台账模板见 `templates/evidence-register.md`。

## 3. 三个维度分别评价

- **核验状态**：未核验 / 单一来源 / 多源一致 / 多源冲突待解释。
- **证据质量**：原始一手 / 权威转述 / 同源转载 / 匿名传闻。
- **研究成熟度**（仅用于研究类信息）：仿真 / 体外 / 动物 / 人体可行性 / 临床研究。

「单一来源」描述的是核验状态，不自动等于低质量；一篇同行评审论文作为单一来源，优于十个同源转载网页。

## 4. 独立验证的判定

- 转载同一新闻稿、论文、数据库的多个页面 = **同一证据**，不算独立验证。
- 真正独立的验证应来自：不同方法论、不同数据生产者、不同利益方。
- 官方/权威记录可支持其**覆盖范围内**的事实；不能用它证明其未覆盖的性能、疗效或商业收益（例：注册证证明合规上市，不证明疗效优劣）。

## 5. 冲突处理

来源冲突时按顺序比较：

1. **定义/口径**是否不同（含不含耗材？出厂价还是终端价？）
2. **时间**（哪条更新？是否跨越政策/价格突变点？）
3. **地区与型号**（国行 vs 海外？A 型 vs B 型？）
4. **方法与样本**

能解释差异时给出有依据的判断并说明；解释不了就**保留冲突并列呈现**，不擅自取舍，也不为了好看取中位数。

## 6. 边界声明（不可违反）

- 搜索未发现只能说明**当前检索条件和结果**，不能证明不存在；报告中写「未查得」并注明检索范围。
- 未访问原文、仅有摘要或二手转述时，明确标注「摘要依据」，**不编造**页码、引文、图表号、定量结果或链接。
- 不把企业提供的内部数字当作公开事实引用；如必须使用，标注来源为「内部假设/企业提供，未独立验证」。

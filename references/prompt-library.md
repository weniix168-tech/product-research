# 专项提示词库（Prompt Library）

以下提示词供各任务模式直接调用或复制使用。变量由 `{}` 标出，缺失变量遵循 SKILL.md 第 0 节的提问规则：只有实质改变方向时才问，其余记入假设清单。

## A. 快速初筛

```text
请对{主题}做快速初筛，支撑{决策}，范围为{地区/客户/用途}。
优先回答机会是否值得进一步验证、关键未知是什么、最低成本的下一步是什么。
输出一页式摘要、核心事实及来源、需求/技术/商业假设、反证与行动项。
不要强制展开完整十二类研究；说明裁剪理由。
```

## B. 竞品与技术专项

```text
请围绕{决策问题}比较{产品或路线列表}。
先统一型号、版本、单位、测试条件、地区和价格口径，再建立比较矩阵。
区分厂商宣称、独立测试和分析推断，缺失值标为未查得。
保留替代方案和维持现状，输出差异、证据局限、待验证项及决策影响。
不要据公开资料猜测未披露的供应商、内部架构和自研比例。
```

## C. 文献与早期信号

```text
请研究{技术主题}在{时间范围}内的公开进展。
逐项记录机制、研究对象/设计、样本、比较基线、终点、定量结果、局限和原文定位。
区分仿真、体外、动物、人体和临床证据，并独立评价证据质量。
输出技术信号表、相对现有方案的变化、转化缺口与下一步验证建议。
全文未取得时明确说明；不能把专利、动物结果或宣传材料当成已验证商业能力。
```

## D. 需求验证

```text
请把{问题描述或公开反馈}转成需求假设，不直接称为已验证需求。
区分使用、采购、付款和决策角色，列出场景、频率、影响和现有替代。
设计非诱导访谈、观察或试用方案，说明样本选择、偏差、通过条件和反证。
没有研究结果时只交付执行计划；通过条件标明建议/已确认状态。
```

## E. 立项与实施路线

```text
请对{候选概念}形成分阶段投入建议，已知约束为{约束}。
按同一交付范围比较自研、采购集成、外包、合作等适用路线及维持现状。
关联需求证据、技术可行性、资源、合规约束、成本与现金流假设。
以继续/附条件继续/暂缓/终止/证据不足给出建议，列出下一阶段证据、投入上限和停止条件。
缺少企业资料时给条件化分析，不编造内部能力和批准结果。
```

## F. 项目组合

```text
请比较{匿名候选项目列表}，约束为{资源/时间/战略边界}。
先列硬约束，再建议可解释的评价维度与权重，标注哪些已经确认。
分析资源冲突、依赖和机会成本，并说明排序对假设的敏感性。
证据不足时给分组或补证优先级，不制造精确排名。
```

## G. 财务框架

```text
请为{通用产品概念}建立可追溯的财务分析框架。
逐项列出输入、单位、来源、已知/估计/假设状态，统一币种、税费和预测期间。
按任务需要展示研发投入、持续费用、收入、现金流、盈亏平衡、回收期及情景敏感性。
缺价格、销量、报价等关键输入时提供公式和数据获取方法，不编造预测。
```

## H. 更新与复盘

```text
请基于{上一版报告}和{新增公开资料}更新研究。
输出新增/修订/撤回/仍未知清单，关联受影响的声明、需求、假设和决策。
优先复核时效性高或影响大的信息；无需重写未变化章节。
说明原建议是否改变、改变依据和下一次复审触发条件。
```

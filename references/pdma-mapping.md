# PDMA 七领域映射（自检用）

参考 PDMA Body of Knowledge（3rd Edition）的七个领域，用作**立项研究的遗漏检查表**。仅依据公开书介与目录整理，不代表 PDMA 官方规定，也不要求每次按七领域逐章写作。

| 领域 | 本仓库对应补充 | 启用条件 |
| --- | --- | --- |
| 管理 | 成功指标、风险、路标、生命周期与决策复盘 | 立项或持续研究 |
| 战略 | 战略匹配、轻量 PIC（背景、聚焦范围、目标、边界） | 机会选择或立项 |
| 组合 | 项目比较、资源容量、依赖、机会成本与排序 | 多项目竞争资源 |
| 过程 | 阶段交付物、证据要求、责任与评审条件 | 需要推进开发或验证 |
| 设计与开发 | 候选概念、设计输入草案、原型试验、需求追溯 | 涉及概念或技术方案 |
| 市场研究 | 二手研究、一手研究计划、购买链、样本偏差与付费意愿 | 需求与市场判断 |
| 文化与团队 | 跨职能协作、职责、分歧处理、试验学习 | 需要组织协同 |

**用法**：完成立项报告后，对照上表逐行问一句「这一领域有没有该说而没说的？」——有则补一节或一段，没有就跳过。映射是检查遗漏的工具，不是写作模板。

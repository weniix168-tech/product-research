# 虚构工作流示例

> **本文件所有场景均为虚构**，仅用于演示 skill 各任务模式的裁剪方式与产出形态。其中任何公司、产品、数字、日期都不指向真实主体；实际使用时请替换为你的任务输入。

## 示例一：快速初筛（通用工业检测工具A）

**输入**：「 handheld 超声探伤仪这个方向值得我们看吗？出处：某展会新闻」

**模式选择**：快速初筛。裁剪说明：不展开财务模型与组织设计，只回答「值不值得进一步验证」。

**简报要点**：

- 判断摘要：市场存在但竞争密集，建议先做 5 家目标客户访谈再决定是否立项。
- 核心事实：{例}全球无损检测市场规模约 X 亿美元（来源：某公开研报，声明类型：分析推断）。
- 关键未知：目标细分（电力巡检 vs 轨交）的真实采购预算未查得。
- 下一步：访谈计划（非诱导提纲、样本 5 家、通过条件=3 家以上表达出明确采购意向——建议值）。

## 示例二：竞品/技术专项（通用消费设备B）

**输入**：「比较 C 方案和 D 方案的技术路线，我们要选第三代平台」

**模式选择**：竞品/技术专项。不展开企业战略。

**产出形态**：统一口径矩阵——先确认 C/D 的型号版本、测试条件、价格口径是否可比；缺失参数标「未查得」；区分厂商宣称与独立测试；保留维持现状选项；最后一列写「证据局限」。

**决策影响**：{例}D 方案在某指标上领先但该数据为厂商宣称、无第三方复现 → 列为待验证项，不直接作为选型依据。

## 示例三：立项与路线决策（社区旧物回收柜C）

**输入**：「我们要不要做智能回收柜？预算 300 万以内」

**模式选择**：立项与路线决策。启用完整报告模块，模块标注：市场洞察（必选）、法规（必选：按目标城市查特种设备与市容相关规定）、财务（必选，但销量输入标注假设）、竞品（必选）、技术（可选）。

**关键动作**：

1. PIC：聚焦 1 个城市 2 个城区试点；明确不做的范围（不自建清运车队）。
2. 路线比较：自研硬件 / 采购现成柜体+自研软件 / 整体外包——同一交付范围比较，表格不预设优劣。
3. 财务：利润≠现金流，按试点现金流算回收期；悲观情景=单点日回收量低于盈亏平衡。
4. 阶段评审：概念验证（1 个柜体 4 周试点，投入上限 20 万，通过条件=周均单量达到 X——建议值）。
5. 决议：附条件继续。

## 示例四：更新与复盘

**输入**：「上季度你给我的回收柜报告，这是近三个月的新资料」

**模式选择**：更新与复盘。

**产出**：新增 3 条（{例}某市新规允许柜体进地铁口）、修订 1 条（某竞品宣布停产，原报告中「竞争加剧」判断减弱）、撤回 1 条（原引用数据系厂商口径，无年报佐证）、仍未知 2 条。结论：维持「附条件继续」，触发复审条件=试点城市政策变化。
